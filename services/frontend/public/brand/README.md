# Provider logos

The Google and GitHub sign-in buttons show the providers' official marks, which this repo does not ship.

1. Download the official files:
   - Google: https://developers.google.com/identity/branding-guidelines
   - GitHub: https://github.com/logos
2. Save them here as `google.svg` and `github.svg`.
3. Set `NEXT_PUBLIC_BRAND_MARKS=1` when building the frontend.

Without that variable the buttons are text-only.
